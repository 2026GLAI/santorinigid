## Как посмотреть сайт прямо сейчас

Откройте командную строку в папке сайта и введите:

```bash
npm run dev
```

Затем откройте в браузере адрес, который покажет программа (обычно
`http://localhost:4321`). Чтобы остановить — нажмите Ctrl+C.

Чтобы собрать готовый сайт для публикации:

```bash
npm run build
```

Готовые файлы появятся в папке `dist` — это и есть ваш сайт.

- **Не придумывал отзывы и оценки.** На старом сайте нет рейтинга в звёздах —

  в символ — это ваш доход, я к ним не притрагивался.
- **Не публиковал сайт в интернет** — это ваше решение и ваши аккаунты.
