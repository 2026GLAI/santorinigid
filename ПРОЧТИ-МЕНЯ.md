## Как посмотреть сайт

**С компьютера:**

```bash
npm run dev
```

**С телефона** (телефон и компьютер в одной сети Wi-Fi):

```bash
node preview-server.cjs
```

Программа покажет адрес вида `http://192.168.1.4:4600` — его и открывайте
на телефоне. Остановить: Ctrl+C.

- **Тёмная тема** — если у гостя на телефоне включён тёмный режим, сайт
  подстроится сам.
- **Красивая карточка при пересылке ссылки** — когда кто-то отправит ссылку на
  ваш сайт в мессенджере, появится фото Ии с подписью, а не пустой прямоугольник.

## Про звёзды в поиске — важное

Вы просили, чтобы у отзывов были звёзды. **С вашего сайта их получить нельзя** —
это правило Google: если компания сама публикует отзывы о себе, звёзды в выдаче
не показываются.

Звёзды берутся из **Google Business Profile** — бесплатной карточки компании.
Это первый пункт в плане продвижения (`docs/promotion-plan.md`).
