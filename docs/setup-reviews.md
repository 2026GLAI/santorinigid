# Как включить приём отзывов с подтверждением

Владимир, это инструкция по шагам. Делается один раз, примерно за 30–40 минут.
После настройки всё работает само.

**Railway не нужен.** Всё делает бесплатный Cloudflare — тот же аккаунт, где
будет хостинг сайта. Ваши проекты на Railway не трогаем.

---

## Что получится в итоге

1. Гость заполняет форму на сайте — **регистрация не нужна**.
2. Вам на **rusantorini@gmail.com** приходит письмо: текст отзыва, фотографии
   и две кнопки — **«Опубликовать»** и **«Удалить»**.
3. Нажимаете «Опубликовать» → отзыв сам появляется на сайте через 2–3 минуты.
   Нажимаете «Удалить» → отзыв стирается навсегда.

**Пока вы не нажали — на сайте нет ничего.** Конкурент физически не может
ничего опубликовать: максимум пришлёт письмо, которое вы удалите одной кнопкой.

---

## Шаг 1. Репозиторий на GitHub

✅ Уже готов: **`2026GLAI/santorinigid`**
(https://github.com/2026GLAI/santorinigid)

Осталось загрузить туда файлы проекта.

## Шаг 2. Токен GitHub (ключ, которым Worker запишет отзыв)

1. Откройте https://github.com/settings/tokens
2. **Generate new token** → **Generate new token (classic)**
3. Название: `santorinigid-reviews`
4. Срок (Expiration): **No expiration** — иначе через год всё перестанет работать
5. Поставьте одну галочку: **repo**
6. **Generate token** → скопируйте строку `ghp_...`

⚠️ Эту строку показывают **один раз**. Скопируйте её в надёжное место.
Кто получит этот токен — сможет менять ваш репозиторий.

## Шаг 3. Сервис писем Resend (бесплатный)

1. Зарегистрируйтесь на https://resend.com — бесплатно 3000 писем в месяц
   (вам хватит с большим запасом)
2. **API Keys** → **Create API Key** → скопируйте строку `re_...`
3. **Domains** → добавьте `santorinigid.com` и внесите записи, которые
   покажет Resend, в DNS Cloudflare. Это нужно, чтобы письма не попадали в спам.

   *Пока домен не подтверждён, письма будут приходить с адреса Resend —
   тоже работает, просто выглядит менее солидно.*

## Шаг 4. Хранилище в Cloudflare

1. Панель Cloudflare → **Workers & Pages** → **KV**
2. **Create a namespace**, название: `REVIEWS`

## Шаг 5. Сам Worker

1. **Workers & Pages** → **Create** → **Create Worker**
2. Название: `santorinigid-reviews` → **Deploy**
3. **Edit code** → удалите весь пример и вставьте содержимое файла
   `worker/review-worker.js` из проекта → **Deploy**

## Шаг 6. Настройки Worker

Откройте Worker → **Settings**.

**Variables and Secrets** — обычные переменные (Type: Text):

| Имя | Значение |
|---|---|
| `OWNER_EMAIL` | `rusantorini@gmail.com` |
| `GITHUB_REPO` | `2026GLAI/santorinigid` |
| `GITHUB_BRANCH` | `main` |
| `SITE_URL` | `https://santorinigid.com` |
| `WORKER_URL` | адрес Worker (Cloudflare покажет его сверху) |

**Те же настройки, но Type: Secret** (значение будет скрыто):

| Имя | Значение |
|---|---|
| `GITHUB_TOKEN` | токен `ghp_...` из шага 2 |
| `RESEND_API_KEY` | ключ `re_...` из шага 3 |
| `ADMIN_SECRET` | придумайте длинную случайную строку, минимум 32 символа |

> `ADMIN_SECRET` — это подпись кнопок в письме. Без неё никто не сможет
> подделать ссылку «Опубликовать». Просто наберите 40 случайных символов.

**Bindings** → **Add** → **KV namespace**:
- Variable name: `REVIEWS`
- KV namespace: выберите созданный в шаге 4

## Шаг 7. Подключить форму к Worker

В файле `src/pages/../components/ReviewForm.astro` найдите строку:

```js
const REVIEW_API = '';
```

Впишите между кавычками адрес Worker и добавьте `/review` в конце:

```js
const REVIEW_API = 'https://santorinigid-reviews.ваш-аккаунт.workers.dev/review';
```

Сохраните, пересоберите сайт (`npm run build`), загрузите на GitHub.

## Проверка

1. Откройте страницу отзывов, заполните форму, отправьте.
2. В течение минуты на `rusantorini@gmail.com` придёт письмо.
3. Нажмите **«Опубликовать»** — откроется страница «Отзыв опубликован».
4. Через 2–3 минуты обновите страницу отзывов — ваш отзыв там.

Если письмо не пришло — проверьте папку «Спам» и что в Worker правильно
записан `RESEND_API_KEY`.

## Частые вопросы

**Сколько это стоит?**
Ноль. Cloudflare Workers — 100 000 запросов в день бесплатно, KV — 100 000
чтений в день, Resend — 3000 писем в месяц. Вам нужно в тысячи раз меньше.

**Что если я случайно удалю нужный отзыв?**
Он останется в вашей почте — письмо никуда не денется. Пришлёте его мне,
добавлю вручную.

**Что если я не отвечу на письмо?**
Отзыв хранится 60 дней, потом удаляется сам. Письмо у вас останется.

**Можно ли удалить уже опубликованный отзыв?**
Да. Отзывы лежат в файле `src/data/reviews.ts` — удаляете нужный блок,
сохраняете, загружаете на GitHub. Сайт пересоберётся сам. Или скажите мне.

**Что будет, если Cloudflare или Resend исчезнут?**
Сайт продолжит работать — он статический. Перестанет работать только форма
отзывов, а уже опубликованные останутся на месте, потому что они лежат
в файле проекта, а не в чужом сервисе. Это и есть независимость.

**Нужен ли Railway?**
Нет. Ваши проекты на Railway этот сайт не трогает.
