# santorinigid.com

Сайт Владимира Лунгу — частного русскоязычного гида на Санторини.

Статический сайт на [Astro](https://astro.build): в готовом виде это обычные
HTML-файлы, без сервера, базы данных и подписок.

## Что внутри

| | |
|---|---|
| Страниц | 12 |
| Файлов JavaScript в сборке | 0 |
| CSS на страницу | 32–39 КБ |
| Внешних зависимостей при загрузке | нет — шрифты свои |
| Счётчиков и трекеров | нет |

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

Просмотр готовой сборки с телефона (в той же сети Wi-Fi):

```bash
node preview-server.cjs
```

## Устройство

```
src/
  data/        данные сайта — правим их, а не разметку страниц
  pages/       страницы
  components/  повторяющиеся блоки
  layouts/     общий каркас
  styles/      дизайн-система и токены
worker/        программы для Cloudflare Workers (отзывы, чат-помощник)
public/        файлы, попадающие в сайт как есть
```

Данные вынесены в `src/data/`: контакты, отзывы, яхты, отели, экскурсии.
Чтобы поменять содержимое сайта, правят их, а не вёрстку.

## Публикация

GitHub Actions собирает сайт при каждом изменении в ветке `main`
и публикует на GitHub Pages. Настройка — в `.github/workflows/deploy.yml`,
там же описаны условия, без которых публикация не пройдёт.

## Особенности

**Стаж считается, а не вписывается.** В `src/data/site.ts` заданы годы
(`ON_ISLAND_SINCE = 1995`, `GUIDE_SINCE = 2012`), а число лет вычисляется
при каждой сборке и склоняется по-русски. Вписанная цифра устарела бы
1 января.

**Отзывы настоящие и без звёзд.** 22 отзыва с Tourister.ru и NeedGuide.ru,
тексты сверены с оригиналами, у каждого ссылка на источник. Оценок в звёздах
нет: их нет и на площадках-источниках, а рисовать несуществующие нельзя.

**Картинки обрабатываются при сборке.** Sharp делает WebP и AVIF в пяти
размерах под разные экраны.

**Ключи доступа в коде отсутствуют.** Они живут в настройках Cloudflare
Workers и в репозиторий не попадают.
